CUSTOMER CHURN ANALYSIS

Objective:

To identify behavioral patterns and technical friction points leading to customer attrition. I developed this solution to move beyond surface-level metrics and uncover the "why" behind customer churn using a multi-layered data approach.

Technical Workflow:

Data Transformation (Power Query): Cleaned and profiled raw CSV data, handled missing values, and established data types to ensure reporting accuracy.

Data Modeling: Created a star schema (or flat-table) structure to optimize report performance.

Calculated Metrics (DAX): Developed custom measures to calculate Churn Rate, Revenue at Risk, and Churn customers allowing for dynamic filtering across Age and Gender segments.

UI/UX Design: Built an interactive dashboard with a focus on visual hierarchy, using custom color themes to improve stakeholder readability.
